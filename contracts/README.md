# contracts/

The **only** directory services may share. Services never import each other's code; they
depend on each other through the machine-readable contracts published here.

| Contract | Provider (owner) | Generated by | Consumers |
|---|---|---|---|
| `modbus/mock-modbus.devices.json` — every simulated device and register | `services/mock-modbus` | `make -C services/mock-modbus contract` | backend-ot dev seed (`tests/seed_db/mock_modbus_seed.py`) |
| `openapi/backend-ot.openapi.json` — backend-ot HTTP API | `services/backend-ot` | *(roadmap Phase 4)* | optimizer, frontend *(future)* |

## Rules

- **The provider owns its contract.** Files here are generated from the provider's code and
  never edited by hand. Change the provider, regenerate, and commit both together.
- **Drift is a test failure.** Each provider has a check that the committed file equals what it
  would generate now (mock-modbus: `tests/test_contract.py`).
- **Consumers validate on read** (e.g. strict pydantic models with `extra="forbid"`), so a
  contract change is noticed instead of silently mis-parsed.
- **Breaking changes bump `version`** inside the file and are called out in the commit, with
  consumers updated in the same change.
